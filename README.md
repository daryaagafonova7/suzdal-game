# Дожить до рассвета в Суздале 🌫

Хоррор-игра по мотивам реальных объявлений посуточной аренды квартир в Суздале (данные Авито, ноябрь 2026). Стиль — «No, I'm not a human» × Five Nights at Freddy's: тёмно-зелёный думер, серые панельки, белая пиксельная рамка галереи.

## Как играть
- Вам показывают 10 активных квартир, одну за другой.
- У каждой — 3 похожие цены: одна настоящая, одна завышена, одна занижена.
- Угадали — +100 очков. Ошиблись — минус 1 из 5 жизней (пиксельные сердечки).
- Потеряли все жизни — эта ночь в Суздале стала последней.
- Прошли все 10 — итоговый счёт, сумма переплаты и вердикт: платёжеспособный миллениал или неплатёжеспособный зумер.

## Запуск локально
Просто откройте `index.html` в браузере — сборка не нужна.

Либо через локальный сервер:
```
npx serve .        # если есть Node
```

## Публикация на GitHub Pages
1. Создайте репозиторий на GitHub.
2. Загрузите в корень репозитория: `index.html`, `style.css`, `data.js`, `game.js`, папку `images/` и `.nojekyll`.
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `/ (root)` → Save.
4. Через минуту игра будет доступна по адресу `https://<username>.github.io/<repo>/`.

Файл `.nojekyll` нужен, чтобы GitHub Pages отдавал статику как есть, без обработки Jekyll.

## Технические детали
- Чистый HTML/CSS/JS, без зависимостей и сборки; мобильная верстка (viewport, safe-area, свайп галереи).
- 48 фотографий сжаты до 900px JPEG q≈70 (~490 КБ суммарно), следующая квартира предзагружается во время игры.
- Скрипты парсинга данных лежат в `tools/` (PowerShell, в репозиторий можно не включать).
